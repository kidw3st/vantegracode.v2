# Vantegra — правила проекта

Сайт студии Vantegra (vantegracode.ru). Полное задание — `VANTEGRA-SITE-PROMPT.md`, план и решения — `PLAN.md`, заглушки — `TODO.md`. Задание главнее брендбука.

## Источники
- Только задание и файлы владельца в этой папке: `logo/`, `fonts/`, `docs/Vantegra-Brandbook.pdf`, кейсы в `cases/` (когда появятся).
- Изображения из брендбука на сайт **не ставим** (решение владельца). Хром — только в готовых рендерах, которых на сайте нет.
- Маскот (хромовый кубик) — запрещён полностью. Текущий vantegracode.ru не открывать.
- Не выдумывать клиентов, кейсы, отзывы, цифры, стаж, команду. Нет данных — нет блока.
- Файлы владельца только копируются, не правятся. SVG логотипа — как есть, через `<img>`.

## Бренд
- Цвета — только токены из `src/styles/tokens.css` (файл не менять; дополнительные числа — `tokens-extra.css`): `--soot` #111111 фон, `--chalk` #F4F2EE текст, `--graphite` #2A2A2A линии, `--ash` #8C8984 подписи, на меле — `--ash-on-chalk`, `--line-on-chalk`. Орбиты — мел 4–20 %.
- Без теней, свечений, градиентов, скруглений карточек и картинок. Исключение владельца — неоновые импульсы на линии под надписью VANTEGRA (`SectionHeader neon`). Скругление pill — только кнопки и теги. Размытие — только у шапки после прокрутки.
- Светлых секций нет (решение владельца): все блоки на саже. Мел как фон — только для будущей светлой темы.
- Шрифты: Tenor Sans — заголовки, только ЗАГЛАВНЫЕ, 400. Manrope — текст, 400/500. Geologica — подписи, цифры, навигация, кнопки, всегда `font-variation-settings: 'SHRP' 100`, у Geologica всегда задавать `font-weight` (по умолчанию ось = 100). Без курсива, без веса выше 500.
- Eyebrow: «01 — Название», Geologica, заглавные, `--ls-label`, `--ash`.
- Эхо-орбиты — единственный декор: эллипсы −12°, ry/rx = 0,306, линия 1–1,5 px, не пересекают логотип (расчёт в `src/lib/orbit.ts`), не больше 4 на экран, за текстом прозрачность ≤ 12 %. Места: первый экран главной, CTA с формой, мобильное меню, успех формы, 404, «О студии».
- Логотип: только мел или сажа, не поворачивать, не растягивать, без эффектов; охранное поле 15 % ширины знака; минимум — знак 24 px, горизонтальный блок 140 px. Ссылка на главную с `aria-label="Vantegra — на главную"`.
- Тон: коротко, спокойно, «мы» / «вы» со строчной, без восклицаний, эмодзи и штампов.

## Код
- Astro 7 static, TS strict, обычный CSS (стили компонентов внутри `.astro`), ванильный TS. Без фреймворков, Tailwind, GSAP, Three.js, smooth-scroll.
- Тексты страниц — из `src/data/site.ts` и коллекций в `src/content/`, не хардкодить. Токены `{…}` подставляет `src/lib/fill.ts`; неизвестный токен ломает сборку.
- Все строки — через `t()` из `src/lib/typograf.ts` (кроме ссылок, телефонов, кода).
- Движение: только `transform`, `opacity`, `stroke-dashoffset`; исключение — `clip-path: inset()` для раскрытия заголовков блоков «занавесом» (решение владельца). Тайминги из токенов; скрытые состояния только под `html.js`; `prefers-reduced-motion` отключает всё, кроме коротких фейдов.
- Ряды карточек на телефоне (до 767 px) — лентой вправо: класс `.rail` (решение владельца). Новые ряды карточек делать так же.
- Скрипты регистрируются через `src/scripts/lifecycle.ts`: init на `astro:page-load`, очистка на `astro:before-swap`.
- После каждого этапа: `npm run build` без ошибок и предупреждений, коммит.
- Проверки: `npm run test` (Playwright), `npm run shots` (скриншоты в `docs/screenshots/`), `npm run links`.
