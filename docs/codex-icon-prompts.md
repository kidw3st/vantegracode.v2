# Пак иконок Vantegra — промпты для Codex

Документ для генерации пака иконок в стиле сайта Vantegra с помощью Codex. Промпты самодостаточные: Codex не знает истории проекта, поэтому в каждом есть пути, правила и способ проверки.

## Как пользоваться

1. Открой Codex в корне репозитория `vantegracode.v2`.
2. Отправь **Промпт 0** (мастер-промпт со стилем). Он задаёт правила для всех следующих.
3. По очереди отправляй **Промпты 1–6** — по одному пакету иконок. После каждого пакета смотри превью (`docs/screenshots/icons-sheet.png`) и правь, если нужно.
4. Отправь **Промпт 7** — компонент `Icon.astro`, манифест и раздел в `/styleguide/`.
5. Отправь **Промпт 8** — автопроверка всего пака и финальная сборка.
6. Пройди **чек-лист приёмки** в конце документа.

Если Codex отходит от стиля — повтори ему абзац «Правила стиля» из Промпта 0 и попроси перерисовать конкретные иконки.

## Промпт 0 — стиль и правила (отправить первым)

```text
Ты работаешь в репозитории сайта студии Vantegra (Astro 7, TypeScript strict, обычный CSS, без UI-библиотек).
Задача серии: нарисовать пак SVG-иконок в стиле бренда. Сейчас только запомни правила — иконки рисуем в следующих сообщениях пакетами.

Контекст бренда
- Тёмный сайт: фон «сажа» #111111, текст и линии «мел» #F4F2EE, подписи «пепел» #8C8984, рамки «графит» #2A2A2A.
- Характер: тихая роскошь и сдержанный Y2K-футуризм. Минимум элементов, точная геометрия, тонкие линии, много воздуха.
- Фирменный мотив — «эхо-орбита»: тонкий эллипс с наклоном −12° и отношением осей ry/rx = 0,306.
- Иконки на сайте уже есть и задают эталон: стрелка ссылок (линия 1,25, острые углы), иконка копирования (два квадрата со сдвигом), шеврон селекта, плюс/минус аккордеона, бургер из двух линий. Посмотри src/components/Arrow.astro, src/components/ContactList.astro (иконка копирования) и src/components/LeadForm.astro (шеврон селекта) — новые иконки должны выглядеть как одно семейство с ними.

Правила стиля (обязательны для каждой иконки)
1. Холст 24×24: viewBox="0 0 24 24", без атрибутов width/height. Рабочая зона 20×20 (поле 2 px с каждой стороны), все координаты в пределах 2…22.
2. Только контур: на корневом <svg> fill="none" stroke="currentColor" stroke-width="1.25" stroke-linecap="square" stroke-linejoin="miter". Цвет не задаётся нигде, кроме currentColor.
3. Единственное исключение из «без заливки» — маленькая точка-ядро: <circle r="1" … fill="currentColor" stroke="none"/> (r от 0,75 до 1,25). Не больше двух точек на иконку.
4. Острые углы. Скругления только там, где это часть предмета: окружность, эллипс, звено цепи, корпус телефона (rx ≤ 2). Карточки, рамки, окна — с прямыми углами.
5. Углы линий — 0°, 45°, 90° и наклон орбиты −12°. Произвольных углов нет. Единственное исключение — бумажный самолётик telegram: его крылья из этих углов не строятся.
   Древко стрелки кончается на 1 ед. раньше острия: иначе квадратный конец линии торчит из-под наконечника.
6. Орбита в иконке рисуется только так: <ellipse cx="…" cy="…" rx="R" ry="R*0.306" transform="rotate(-12 cx cy)"/>. Это единственный разрешённый transform. Орбиту используем там, где она что-то значит (технологии, цикл, поддержка, мир), — не больше одной на иконку.
7. Минимум деталей: 2–6 простых фигур. Читается на 16 px, красиво на 48 px.
8. Оптический размер: квадратные формы около 16×16, круглые — около 18×18, длинные горизонтальные — около 18×12. Иконки центрированы оптически, а не только математически.
9. Координаты кратны 0,25; предпочтительно 0,5. Никаких 7.3812. Единственное исключение — ry орбиты: rx × 0,306, округлённое до 0,01.
10. Запрещено: обводка иконки кружком или квадратом-подложкой («иконка в кружке»), градиенты, фильтры, тени, маски, текст и цифры внутри иконки, лица и эмоции, эмодзи-стилистика, рисованные или «живые» линии, перерисовка логотипа Vantegra (V с орбитой).
11. Каждую иконку рисуешь сам, с нуля. Не копируй и не переделывай Lucide, Feather, Heroicons, Tabler, Phosphor и другие наборы — пак должен быть собственным.
12. Один файл — одна иконка: src/assets/icons/<имя>.svg, имя — латиница в kebab-case (arrow-right.svg). Файл ≤ 1 КБ, одна строка, без комментариев, без id и class, порядок атрибутов как в эталоне.

Эталоны (точно в этом стиле)

arrow-right.svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.25" stroke-linecap="square" stroke-linejoin="miter"><path d="M3.5 12H19M14.5 6.5L20 12l-5.5 5.5"/></svg>

copy.svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.25" stroke-linecap="square" stroke-linejoin="miter"><path d="M8.5 8.5h12v12h-12zM3.5 15.5v-12h12"/></svg>

orbit.svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.25" stroke-linecap="square" stroke-linejoin="miter"><ellipse cx="12" cy="12" rx="9.5" ry="2.91" transform="rotate(-12 12 12)"/><circle cx="12" cy="12" r="1.25" fill="currentColor" stroke="none"/></svg>

Превью после каждого пакета
- Создай (один раз) скрипт tests/icons-sheet.mjs: берёт все src/assets/icons/*.svg и через Playwright (он уже в devDependencies) рисует лист превью — фон #111111, иконки цветом #F4F2EE, под каждой имя (шрифт любой системный, 11 px, цвет #8C8984), сетка по 8 в ряд, каждая иконка в двух размерах: 24 px и 48 px. Сохраняет docs/screenshots/icons-sheet.png (deviceScaleFactor 2). Добавь в package.json скрипт "icons:sheet".
- После каждого пакета запускай npm run icons:sheet, открывай картинку, сам проверяй, что иконки одного семейства (толщина, плотность, оптический размер), и исправляй выбивающиеся.

Ничего, кроме src/assets/icons/, tests/icons-sheet.mjs и строки скрипта в package.json, пока не трогай. Новые зависимости не ставь.
Ответь коротко: «Правила понял» и список того, что создашь в следующем шаге.
```

## Промпт 7 — компонент, манифест и витрина

```text
Подключи пак иконок к сайту. Правила стиля — из Промпта 0.

1. src/assets/icons/manifest.json — массив объектов { "name": "arrow-right", "group": "ui" | "contact" | "service" | "process" | "feature" | "brand", "label": "Стрелка вправо" } для каждой иконки. label — по-русски, коротко.

2. src/components/Icon.astro — инлайн-иконка по имени:
   - пропсы: name (обязательный, тип — объединение имён из manifest.json), size (число, px, по умолчанию 24), label (строка, необязательно), class;
   - SVG берётся через import.meta.glob('../assets/icons/*.svg', { query: '?raw', import: 'default', eager: true }) и вставляется инлайн (set:html), к корню добавляются width/height = size и class="icon";
   - без label: aria-hidden="true" focusable="false"; с label: role="img" и <title> внутри SVG;
   - неизвестное имя — ошибка сборки с понятным текстом;
   - стили компонента: display: inline-block; flex: none; vertical-align: middle; цвет — currentColor, толщину не трогать.
```
