- В `site.ts`, `prices.yaml` и `faq.yaml` незаполненное значение — `null`. Цены — числами, без «₽». Срок — в родительном падеже: «2 недель», «1 месяца».

## 1. Задача

Ты — ведущий фронтенд-разработчик и дизайнер интерфейсов. Сделай с нуля сайт студии разработки **Vantegra** для домена vantegracode.ru. Нужны главная и семь разделов: **Услуги, Цены, Работы, О студии, Блог, Вопросы, Контакты**.

Характер бренда — тихая роскошь и сдержанный Y2K-футуризм. Минимум элементов, много пустоты, точная геометрия, крупная типографика, тонкие линии. Сайт тёмный: мел на саже.

Главная проверка готовности: сайт выглядит как продолжение брендбука Vantegra из материалов владельца, а не как шаблон.

## 3. Технологии и структура

- **Astro**, последняя стабильная версия (Node ≥ 22.12). Коллекции — через `src/content.config.ts` с загрузчиками `glob()` и `file()` (zod из `astro/zod`). TypeScript в режиме `strict`. В конфиге: `output: 'static'`, `site: 'https://vantegracode.ru'`, `trailingSlash: 'always'`.
- **Стили** — обычный CSS. Файл `src/styles/tokens.css` создаётся дословно из **Приложения А** в конце этого задания и подключается первым. Рядом лежат `base.css`, `typography.css`, `motion.css`. Стили компонентов пишутся внутри `.astro`.
- **JS** — только ванильный TypeScript и только для меню, появления блоков, орбит, фильтров, аккордеона и формы. Без React, Vue и других фреймворков.
- **Контент** — Astro Content Collections со схемами zod:
  - `src/content/services/*.md` — услуги;
  - кейсы — загрузчик `glob()` прямо из папки кейсов в материалах владельца (формат описания — как у владельца; если его нет, используй структуру из п. 9.4). Разделы тела парсятся: «Результат» — строки «значение — подпись», «Стек» — через запятую. Кейс, где остались `[ ]`, на сайт не попадает. Сортировка — по году, новые первыми. Если кейсов нет, это не ошибка;
  - `src/content/blog/*.md` — статьи;
  - `src/content/faq.yaml` — вопросы;
  - `src/content/prices.yaml` — цены.
  
  Контакты, реквизиты, условия, номер Метрики и тексты CTA — в одном файле `src/data/site.ts`. На страницах тексты не хардкодятся.
- **Изображения** — `astro:assets` (`<Picture>`: AVIF и WebP, явные width и height). Ленивая загрузка у всех картинок, кроме первого экрана.
- **Типографика** — npm-пакет `typograf` (локаль ru), только при сборке, только для текстовых полей (не для ссылок, телефонов, ID и кода). В клиентский JS не попадает.
- **Интеграции:** `@astrojs/sitemap`, `@astrojs/rss`.
- **Форма** — PHP-обработчик `public/api/lead.php` (раздел 10).
- **Проверки** — Playwright в dev-зависимостях: скриншоты и автотесты.
- Node LTS, npm. Инициализируй git и делай коммит после каждого этапа из раздела 13.

## 4. Бренд-система

Ориентир — брендбук из материалов владельца. Перед вёрсткой просмотри страницы 03, 04, 07–14 и 19. Страницы про маскота пропусти.

### 4.1 Цвета (стр. 08, 10)

| Токен | HEX | Роль |
|---|---|---|
| `--soot` | #111111 | Основной фон сайта |
| `--chalk` | #F4F2EE | Текст и логотип на тёмном; фон светлых секций |
| `--graphite` | #2A2A2A | Рамки, линии, поверхности на тёмном |
| `--ash` | #8C8984 | Подписи и второстепенный текст на тёмном |
| `--ash-on-chalk` | #6E6B66 | Второстепенный текст на меле |
| `--line-on-chalk` | #DCD8D1 | Линии на меле |

- Пропорция на сайте: 80 % сажа, 15 % мел, 5 % графит и пепел.
- Светлая секция (фон мел, текст сажа) — не больше одной на странице, для ритма.
- Контраст. Мел на саже — 16,9:1. Пепел на саже — 5,4:1: подходит для мелкого текста. Пепел на графите — 4,1:1: только для текста от 24 px. Пепел на меле — 3,1:1: нельзя, на меле используй `--ash-on-chalk` (4,75:1).

### 4.2 Шрифты (стр. 11)

| Шрифт | Роль | Правила |
|---|---|---|
| **Tenor Sans** | Заголовки H1–H3, крупные надписи | Только ЗАГЛАВНЫЕ, разрядка +8–16 %, одно начертание 400 |
| **Manrope** | Весь основной текст, кнопки-ссылки, поля формы | Строчные, без разрядки, только 400 и 500 |
| **Geologica** | Подписи (eyebrow), номера, цифры, даты, цены, коды, навигация, кнопки | Всегда `font-variation-settings: 'SHRP' 100`. Подписи — 400, ЗАГЛАВНЫЕ, разрядка 0,24–0,3em, 12–13 px. Крупные цифры — 300 |

- Кегли, межстрочные, разрядка и тайминги берутся из `tokens.css`. Числа, прямо указанные в этом файле, тоже допустимы: вынеси их в `src/styles/tokens-extra.css`. Сам `tokens.css` не меняется.
- Курсива и жирного выше 500 нет.
- Строка текста — не длиннее 68 знаков.
- Заголовкам — `text-wrap: balance`, абзацам — `text-wrap: pretty`.
- Предзагружай (`preload`) только Tenor Sans и Manrope.

### 4.3 Русская типографика
- Кавычки «ёлочки», тире «—» с неразрывным пробелом перед ним, «–» в диапазонах (10–19).
- Неразрывный пробел после предлогов и союзов из 1–2 букв, между числом и единицей (6 недель, 350 000 ₽) и в разрядах чисел (11 751).
- В заголовках не должно быть висячих предлогов и переносов слов. Если длинное слово заглавными не влезает на экран 320–480 px, уменьши кегль и разрядку заголовка на этих ширинах. В слове «КОНФИДЕНЦИАЛЬНОСТИ» допустим `&shy;`.
- «Ё» везде, где она есть.
- Всё это делает `typograf` при сборке. Строки в компонентах тоже прогоняй через него.

### 4.4 Логотип (стр. 05–07, 09, 12)

| Версия | Где на сайте |
|---|---|
| Вертикальный блок, мел | Первый экран главной, по центру |
| Горизонтальный блок, мел | Шапка: 156 px по ширине на десктопе, 140 px на мобильном. Подвал: 180 px |
| Знак, мел | Мобильное меню, страница 404, служебные места |
| Знак, сажа / блоки, сажа | Только на светлой секции |

- Охранное поле — 15 % ширины знака со всех сторон. В эту зону не заходят текст, края экрана, кнопки и орбиты.
- Минимальная ширина: знак — 24 px, горизонтальный блок — 140 px.
- **Нельзя:** поворачивать, растягивать, перекрашивать (только мел или сажа), добавлять тени и свечение, ставить на пёстрый фон или фото, набирать VANTEGRA шрифтом, анимировать форму знака. Допустимо только появление: прозрачность и масштаб 0,98 → 1.
- Ссылка с логотипа ведёт на главную, `aria-label="Vantegra — на главную"`.

### 4.5 Эхо-орбиты — единственный декоративный элемент (стр. 13, 19)
- Тонкие эллипсы с наклоном **−12°**, как у орбиты в знаке. Соотношение осей ry / rx = 0,306.
- Линия 1–1,5 px (`vector-effect: non-scaling-stroke`). Цвет — мел с прозрачностью 4–20 % (`--orbit-faint`, `--orbit`, `--orbit-strong`). Заливки нет.
- **Огибают логотип и никогда его не пересекают.** Внутренний эллипс целиком содержит логотип вместе с охранным полем. Проверяй это расчётом в компоненте, не на глаз.
- Не больше 4 эллипсов на экран. Они лежат под текстом (z-index ниже). Если кольцо проходит за текстом, его прозрачность не выше 12 %.
- Где логотипа нет (CTA, мобильное меню, успех формы), центр орбит — центр блока, и они просто уходят за края.
- Где используются: первый экран главной, блок CTA с формой (бледнее), мобильное меню, сообщение об успехе формы, страница 404, «О студии» — вокруг знака. Больше нигде.

### 4.6 Хром и изображения (стр. 04, 14)
- Хром — материал знака только в готовых рендерах из материалов владельца. В интерфейсе логотип всегда плоский SVG. Хром нельзя имитировать градиентами, бликами или металлическим текстом.
- У тёмных изображений фон ровно #111111. Ставь их на `--soot` без рамок: они сливаются с фоном.
- Изображения квадратные или прямоугольные, без скруглений. У mood-* края не ровно #111111 — им всегда рамка 1 px `--graphite`. После кодирования в AVIF/WebP проверь, что края chrome-mark и chrome-orbit не дают видимого прямоугольника. Ширина картинок «во всю ширину» не больше `--maxw`. На chalk-paper — только текст цвета сажи.
- Где какое изображение:

| Изображение (имя в проекте) | Место |
|---|---|
| хромовый знак V с орбитой на тёмном фоне (`chrome-mark`) | Главная, блок «Идея» |
| хромовая орбита без буквы (`chrome-orbit`) | «О студии» — первый экран; страница 404 |
| жидкий хром, вертикальный кадр (`liquid-chrome`) | «Контакты» — вертикальная картинка (только десктоп) |
| настроение: хромовая сфера, стекло, архитектура, световой эллипс (`mood-sphere`, `mood-glass`, `mood-architecture`, `mood-light-trail`) | «О студии» — лента настроения |
| `mood-sphere` | Страница услуги «Аудит сайта» |
| `mood-light-trail` | Обложка статьи блога по умолчанию |
| фактура мелованной бумаги (`chalk-paper`), если есть | Не обязательно: фон единственной светлой секции |
| `og-default` | og:image по умолчанию |

### 4.7 Сетка и ритм
- 12 колонок. Максимальная ширина контента — `--maxw` (1728 px). Поля — `--gutter` (96 px на 1920, 20 px на 375).
- Вертикальный ритм секций — `--section-y`, отступы — только шкала `--space-*`.
- Композиция как в брендбуке. Подпись-eyebrow сверху слева в формате «02 — Услуги». Заголовок крупно. Поясняющий текст — в правой части сетки (колонки 7–12), а не под заголовком на всю ширину. Асимметрия и воздух важнее заполненности.
- Брейкпоинты: 375, 768, 1024, 1280, 1440, 1920. Без горизонтального скролла от 320 до 2560 px.

### 4.8 Тон текста
- Коротко, спокойно, точно. Говорим от «мы», к клиенту — «вы» со строчной.
- Предложения до 20 слов, текстовый блок до 40 слов, описание в карточке до 15 слов.
- Без восклицательных знаков, эмодзи и штампов: «команда профессионалов», «индивидуальный подход», «под ключ», «уникальный», «качественно и в срок».
- Цифры вместо прилагательных, но только реальные: из раздела 0 и из кейсов.
- Готовые тексты из этого файла используй дословно, правь только типографику. Сам пишешь только: три стартовые статьи блога (п. 9.6), каркасы политики и согласия, alt-тексты, SEO-поля, микрокопию интерфейса (ошибки полей, aria-подписи, «Похожие статьи»). ## 7. Движение

Общие правила:
- Движение — только `transform`, `opacity` и `stroke-dashoffset`. Смены цвета, рамки и фона на наведении и аккордеон через `grid-template-rows` разрешены.
- Скрытое начальное состояние (`[data-reveal]`, первый экран) — только при классе `.js` на `<html>`. Без JS всё видно сразу. H1 и лид первого экрана не стартуют с нулевой прозрачности: только сдвиг на 8 px, чтобы не портить LCP.
- Никакого перехвата скролла, плавного скролла, кастомного курсора и прелоадеров.
- При `prefers-reduced-motion: reduce` остаются только короткие (до 200 мс) смены прозрачности. Отрисовка, вращение, параллакс и масштабирование выключаются.
- Тайминги и easing — только из токенов (`--ease-out`, `--ease-in-out`, `--dur-*`, `--stagger`).

| Где | Что |
|---|---|
| Первый экран | Орбиты прорисовываются (`pathLength=1`, dashoffset 1 → 0) за 1600 мс со сдвигом 160 мс между кольцами. Логотип: прозрачность 0 → 1 и масштаб 0,98 → 1 за 900 мс с задержкой 200 мс. Тексты и кнопки поднимаются на 16 px с проявлением, по очереди через 70 мс, начиная с 500 мс |
| Орбиты в покое | Каждое кольцо медленно покачивается вокруг −12° (±0,8°) с периодом 20–28 с, у каждого свой период и фаза. Параллакс от курсора — до 8 px, только для `(pointer: fine)`, сглаживание через requestAnimationFrame. Когда блок вне экрана, анимация на паузе (IntersectionObserver) |
| Появление при скролле | `[data-reveal]`: подъём на 16 px и проявление, 600 мс, один раз, порог 0,15. Дочерние элементы — со сдвигом 70 мс |
| Блок «Идея» на главной | Картинка `chrome-mark` при входе в экран уменьшается с 1,06 до 1. CSS scroll-driven animation (`animation-timeline: view()`). Где не поддерживается — статично |
| Наведение | Ссылки: подчёркивание растёт слева направо, 300 мс. Кнопки: инверсия, 200 мс. Карточки: рамка, сдвиг стрелки на 4 px; у картинок кейсов — масштаб 1,03 за 600 мс |
| Переходы между страницами | Astro View Transitions (`<ClientRouter />`): перекрёстное проявление 250 мс, шапка — `transition:persist`. Все скрипты переинициализируются на `astro:page-load` и снимают свои обработчики, observers и rAF на `astro:before-swap`. После перехода шапка обновляет активную ссылку и `aria-current`, мобильное меню закрывается, блокировка скролла снимается |
| Аккордеон | Высота через `grid-template-rows: 0fr → 1fr`, 300 мс. Плюс превращается в минус поворотом |
| Мобильное меню | Проявление 250 мс, ссылки поднимаются по очереди |

**`public/api/lead.php`** (PHP 8+):
- Принимает POST как form-urlencoded и как JSON. Проверяет `Origin` / `Referer` по домену.
- Повторяет все проверки полей. Отсекает ловушку и отправки быстрее 3 секунд после загрузки. Время ставит JS в скрытое поле на `astro:page-load`; если поле пустое (нет JS), эта проверка пропускается. В CSV экранирует ячейки, которые начинаются с `= + - @`. Лимит — 5 заявок в час с одного IP, хранение в файле.

- Отвечает JSON `{ "ok": true }` или `{ "ok": false, "error": "…" }`, на обычный POST — редиректом.
- Настройки — в `config.php`, лучше вне публичной папки (путь задаётся в `lead.php`). В README предупреди: при заливке `dist/` с удалением лишних файлов `config.php` не должен стираться. `*.sample.php` закрыт для доступа. В репозитории лежит только `config.sample.php`. `config.php` — в `.gitignore`. `api/.htaccess` запрещает прямой доступ к `config.php` и данным.

- `public/.htaccess` для Apache: `ErrorDocument 404 /404.html`, редирект на HTTPS и на адреса со слешем (кроме реальных файлов, путей с точкой и `/api/` — POST на `lead.php` не редиректить), кеш `immutable` только для `/_astro/` (для `/fonts/` — 30 дней), `Referrer-Policy: strict-origin-when-cross-origin`, сжатие, базовые заголовки безопасности (HSTS, `X-Content-Type-Options`, `Referrer-Policy`, `X-Frame-Options`).
